## Background Images

> [!NOTE]
> On systems that use a Jumper PAK, the maximum PNG file size that can be loaded is reduced.

The Theme settings pane also supports animated image and texture packages.
Ready-made packages can be downloaded from
[N64FlashcartMenuThemes](https://github.com/rmmh/N64FlashcartMenuThemes).
See [the PNG theme format](external_theme_format.md) for installation and authoring.

### How to add a background image
First copy an image in `.PNG` or `.JPEG` format with a maximum size of `640x480` to anywhere on the SD card. Then when the N64FlashcartMenu is loaded on the N64, browse to the image and then press the `A` Button to preview it on the screen. Press the `A` Button again to open up the confirmation message, which will ask if you want to set a new background image.
