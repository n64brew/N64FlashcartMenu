## Background Images

> [!NOTE]
> On systems that use a Jumper PAK, available memory limits the size of images that can be loaded; the maximum PNG file size is reduced.

### How to add a background image
First copy a `.PNG`, `.JPG`, or `.JPEG` image with a size of `640x480` to anywhere on the SD card. JPEG files must be exported as baseline, non-progressive JPEGs. Then when the N64FlashcartMenu is loaded on the N64, browse to the image and then press the `A` Button to preview it on the screen. Press the `A` Button again to open up the confirmation message, which will ask if you want to set a new background image.
