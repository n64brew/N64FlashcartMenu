## 64DD Disk support

Specific flashcarts (such as the [SummerCart64](https://summercart64.dev) and EverDrive-64 Pro) can load, run, and save native 64DD disk images without a physical drive connected to the N64 or conversion ROMs.

To load and run 64DD disk images, place the required 64DD IPL dumps in the `/menu/64ddipl` folder on the SD card.
For more details, follow [this guide on the 64dd.org website](https://64dd.org/tutorial_sc64.html).

> [!TIP]
> Expansion disks expect the same region as the ROM image (Japan -> Japan | US -> US).

### EverDrive-64 Pro

Use writable, native-endian 64,931,840-byte `.ndd` images and a matching 4 MiB
IPL. An Expansion Pak is required; disconnect a physical 64DD.

Preview a disk and press A to start it standalone. For a cartridge/disk combo,
preview the cartridge, return with B, then preview the disk and press Z. Combo
ROMs can be up to 120 MiB.

Keep a disk-swap group in the same directory. The firmware discovers the group;
press the cartridge's physical button to advance disks. The menu preview's slot
count does not limit the firmware group.

Set the clock in Settings > Time before launching a disk. Firmware `26.1014`
does not apply clock changes requested through native DD RTC SET commands.

### Conversion ROMs
The N64Flashcart Menu is able to load and run conversion ROMs (but does not perform saves).

### SummerCart64 disk swapping

> [!WARNING]
> Swapping 64DD disks through the menu is experimental and requires an NTSC region console.

The menu does not "yet" fully support disk swapping (WiP), however it is supported in the firmware (and can be used by the SummerCart64 terminal app).

A maximum of 3 swap disks (in addition to the primary first loaded disk) are supported by the SummerCart64 at any one time.

For correct swapping, ensure that you switch them in a compatible context:
Disk Swap Compatibility:
- From DMPJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DMTJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DMGJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DMBJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DKKJ: itself, and DKDJ (required)
- From DSCJ: DMPJ

It is preferable that disks are switched back to the primary disk between each swap, for example: 1, 2, 1, 3, 1, 4...

To use it, press the cart button when a DD disk is running, and it should display an eject prompt. Once the new disk is loaded, press the console's reboot button.

### Expansion disks
N64 and 64DD Compatible Combo Matches:
- Mario Party 1:           CLBx -> ELBx
- F-Zero X:                CFZx -> EFZx
- Zelda OoT:               CZLx -> EZLx
- Pokémon Stadium 1 (JPN): CPSJ -> xPSJ (E to Z)
- Pokémon Stadium 2 (JPN): CP2J -> xP2J (E to Z)
- Dezaemon 3D:             CDZx -> EDZx & DEZA (Prototype)
